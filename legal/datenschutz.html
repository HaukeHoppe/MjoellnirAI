5. KI-Chat und Nutzung der OpenAI API

Funktionsweise und Speicherung der Chats

Der KI-Chat läuft in einer auf unserem eigenen Server betriebenen Chat-Anwendung (Open WebUI). Sie wird ohne Registrierung genutzt: Alle Besucher werden automatisch mit einem gemeinsamen, anonymen Gast-Zugang angemeldet. Es werden weder Name noch E-Mail-Adresse von Ihnen erhoben.

Chats werden ausschließlich als temporäre Chats geführt und nicht in unserer Datenbank gespeichert. Ihre Eingaben werden auf unserem Server nur für die Dauer der Beantwortung verarbeitet. Vom KI-Modell erzeugte Texte, die aus Ihren Eingaben abgeleitet sind (z. B. Vorschläge für Folgefragen oder intern verworfene Aussagen der Antwortprüfung), können in den technischen Logs unseres Servers erscheinen; diese werden nach spätestens 14 Tagen gelöscht.

Übermittlung an OpenAI

Zur Beantwortung Ihrer Fragen nutzen wir die API von OpenAI. Ihre Eingaben in den Chat sowie die dafür benötigten Textauszüge aus unserer Wissensdatenbank werden an OpenAI übermittelt und dort verarbeitet, um die Antwort zu erzeugen. Unser Server ruft die API auf; Ihr Browser stellt keine direkte Verbindung zu OpenAI her, Ihre IP-Adresse wird daher nicht an OpenAI übermittelt.
